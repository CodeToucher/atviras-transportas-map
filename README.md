# Atviras Transportas – offline map pack

Vector basemap for the Atviras Transportas app. The pack covers Vilnius at zoom 0–15 and is stored as a single PMTiles archive (~28 MB).

- Data: © OpenStreetMap contributors, [ODbL](https://opendatacommons.org/licenses/odbl/)
- Tiles/style: [Protomaps](https://protomaps.com/) (BSD-3-Clause)
- Download: [maps-v1 release](https://github.com/CodeToucher/atviras-transportas-map/releases/tag/maps-v1)

This repository only hosts the map asset. The app itself lives in a private repository.
